# Платформа подбора ИТ-специалистов (спецтрек ФСП)

Единый язык платформы, где работодатель сам выходит на кандидата из категоризированной базы.

## Язык

**Подтверждённый результат**:
Запись о результате человека, полученная из внешнего реестра (сейчас ФСП через FSP ID), с указанием источника, места и роли. Влияет на ранжирование внутри категории, но не на грейд.
_Избегать_: достижение, ачивка, бейдж

**Награда**:
Внутренняя отметка геймификации (например, «Первый пройденный тест»), которую система выдаёт за активность на самой платформе. На подбор не влияет.
_Избегать_: достижение, подтверждённый результат

**Источник результатов**:
Внешний реестр, из которого приходят подтверждённые результаты (сейчас ФСП).
_Избегать_: интеграция, провайдер — когда речь о самих данных

**Работодатель**:
Компания, которая ищет кандидатов в категоризированной базе и сама направляет им приглашения с зарплатой.
_Избегать_: организация, компания-клиент

**Внешняя учётная запись**:
Связь пользователя платформы с его аккаунтом во внешней системе идентификации (сейчас FSP ID). По ней подтягиваются подтверждённые результаты.
_Избегать_: FSP-номер, логин ФСП

**Категория**:
Группа однотипных кандидатов, заданная связкой специализации и грейда. Внутри категории кандидатов сравнивают между собой.
_Избегать_: сегмент, уровень

**Грейд**:
Уровень навыков (junior, middle, senior), который заявляет сам кандидат и который подтверждает только тест по категории. Стаж в годах — отдельный атрибут профиля.
_Избегать_: опыт, стаж, разряд

## Связи

- **Грейд** подтверждается только тестом; **Подтверждённый результат** на грейд не влияет

- **Подтверждённый результат** принадлежит одному кандидату и ровно одному **Источнику результатов**
- **Награда** никогда не превращается в **Подтверждённый результат**

## Пример диалога

> **Разработчик:** «Кандидат получил награду "Первый пройденный тест" — поднимаем его в подборке?»
> **Эксперт:** «Нет. Подборку двигает только подтверждённый результат, например призовое место ФСП по программированию БАС. Награда — для мотивации внутри платформы.»

## Отмеченные неоднозначности

- Внешний результат соревнований и внутренняя отметка геймификации — разные сущности: **Подтверждённый результат** и **Награда**.
