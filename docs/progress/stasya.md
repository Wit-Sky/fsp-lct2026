### Ошибки
1. **Заметно жюри.** «У меня нет истории ФСП» на шаге 2 ничего не делает, пока не перезагрузить страницу.
   `Journey.tsx`: кнопка пишет `FSP_SKIP_KEY` в localStorage и вызывает `profile.refetch()`; профиль приходит тот же,
   React Query не перерисовывает экран, `skipped()` не пересчитывается. Кроме того, отметка живёт только в браузере:
   на другом устройстве кандидат после теста снова видит «Шаг 2». (Евгению)
2. **Заметно жюри.** Если тест истёк по таймеру, «Мой путь» снова показывает шаг 3 без слова о том, что было с попыткой;
   «Начать тест» продолжает старую попытку. (Евгению/Ване)
3. **Мелочь.** С «Соседние грейды» выдача обрезана до 50, и «Найдено: 50» — это лимит, а не число найденных
   (в трёх категориях 136). Из-за этого «Только с результатами ФСП» вместе с соседними грейдами не меняет число (50 и 50). (Ване/Евгению)
4. **Мелочь.** На шаге «Мой путь» лишняя точка: «✓. Профиль». Демо-кандидат без ФИО — заголовок «Мой путь, Кандидат».
5. **Мелочь.** Склонение: «44 кандидатов» (надо «44 кандидата»); «Почему он здесь» и «подтверждён» у кандидаток.
   θ на странице итога с точкой (−2.61), в подборке — с запятой.
6. **Известное, ещё не исправлено:** токен в адресе `GET /api/auth/fsp/authorize?token=…` (видно в запросах); демо-кандидат общий —
   после этого прогона у него привязан FSP-900000 и есть попытка backend/middle с кулдауном.
