# 9. Концепции за рамками MVP

## Защита от фиктивных вакансий
- Рейтинг ответов работодателя: доля приглашений, по которым работодатель ответил кандидату в срок.
- Доля приглашений без найма: аномально высокая — сигнал «сбор контактов», ограничение числа приглашений.
- Подтверждение компании по ИНН как добровольная метка доверия.
- Зарплата от–до обязательна — вакансию без денег опубликовать нельзя.

## Интеграция с ATS
- Вебхуки статусов приглашений и откликов (sent, viewed, accepted, declined).
- Экспорт карточки кандидата (с его согласия) в JSON и HR-XML.

## Регулярные задания от работодателей
Работодатель публикует задание по специализации со свободным ответом; ответы освежают профиль кандидата
(компонент freshness) и дают работодателю повод для приглашения.

## Кандидаты 16–17 лет и 152-ФЗ
- Дата рождения в профиле; младше 18 лет — обязательное согласие родителя, работодатель видит пометку «несовершеннолетний».
- Согласие на обработку персональных данных обязательно; кандидат управляет видимостью полей; контакты раскрываются только с его согласия.
