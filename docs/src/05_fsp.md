# 5. Интеграция с реестром ФСП и FSP ID (Keycloak)

## Поток входа (OIDC, authorization code)
1. Кандидат нажимает «Войти через FSP ID»; бэкенд перенаправляет на `/auth/fsp/authorize` с `client_id`, `redirect_uri`,
   `state` и `scope=openid profile email`.
2. Keycloak ФСП аутентифицирует пользователя и возвращает код на `/auth/fsp/callback`.
3. Бэкенд обменивает код на `id_token` и `access_token`, проверяет подпись и `state`, читает claims.
4. Создаётся или находится внешняя учётная запись `ExternalIdentity(provider='fsp', subject=sub)`, уникальная по паре
   (provider, subject), и привязывается к пользователю.
5. По `subject` запрашиваются результаты участника из реестра ФСП и импортируются как подтверждённые результаты.

На демо Keycloak имитируется: те же эндпоинты и тот же обмен, данные берутся из `data/fsp_registry.json`
(все кандидаты с FSP ID и 5 «свободных» участников для показа привязки).

## Какие поля берём и зачем
| Поле | Откуда | Зачем |
|---|---|---|
| `sub` | id_token | ключ внешней учётной записи |
| `name`, `email` | id_token | предзаполнение профиля (кандидат может исправить) |
| соревнование, дисциплина, год, место, роль, командный или личный зачёт | реестр ФСП | подтверждённый результат, компонент `fsp_score` и объяснение в подборке |

## Подтверждённый результат и источник
`VerifiedResult(source, external_id, event, discipline, year, place, role, team)` — подтверждённый результат из
источника результатов. Поле `source` сейчас равно `fsp`; другие источники (олимпиады, хакатоны) добавляются без
изменения схемы. Термин — «подтверждённый результат», не «достижение» (см. `CONTEXT.md`).

## Замена имитации на боевой Keycloak
1. Зарегистрировать клиента в realm ФСП (confidential client, redirect URI стенда).
2. Указать в `.env` адрес realm, `client_id`, `client_secret`; адреса authorize, token и jwks берутся из
   `/.well-known/openid-configuration`.
3. Заменить источник результатов с файла на API реестра ФСП — функция `profile.import_results(source, claims, registry)`
   принимает данные и не зависит от транспорта.

## Если истории ФСП нет
Кандидат выбирает «У меня нет истории ФСП» или привязывает FSP ID без результатов. Путь не блокируется,
`fsp_score = 0`, в объяснении подборки — «нет истории ФСП», оценка идёт по тесту и навыкам.
