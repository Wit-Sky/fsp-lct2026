# Приложение Б. Интерфейс

Снимки сделаны на стенде https://81-26-180-5.sslip.io 11.10.2026. Сквозной путь целиком показан в видео демонстрации.

**Кандидат: «Мой путь».** Четыре шага: профиль, ФСП ID (или «У меня нет истории ФСП»), специализация с грейдом
и тест, категория. Грейд кандидат выбирает сам, тест его подтверждает.

![](img/ui_journey.png)

**Экспресс-тест.** 10 заданий, общий таймер 5 минут, вернуться к заданию нельзя. Числа, код и порядок вариантов
у каждого кандидата свои.

![](img/ui_test.png)

**Итог теста.** Оценка θ на шкале с порогами грейдов, разбор по темам, дата повтора и тест на уровень ниже сразу.

![](img/ui_result.png)

**Работодатель: подборка по потребности.** Целевая и соседние категории с числом подтверждённых кандидатов,
фильтры, которые только сужают выдачу, и раскрытое «Почему в подборке» с вкладом каждого фактора.

![](img/ui_matches.png)

**Приглашение.** Сообщение, зарплата от–до с пометкой гросс или нетто, способ связи. Контакты кандидата откроются
после принятия.

![](img/ui_invite.png)

**Мобильная вёрстка (375 пикселей).** Без горизонтальной прокрутки: меню и категории листаются лентой,
фильтры сворачиваются.

![](img/ui_mobile.png)
