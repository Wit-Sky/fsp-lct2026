# Банк заданий БАС — образцы на вычитку

Сгенерировано из `backend/app/bank/bas_*.py`: по 2 варианта каждого шаблона с правильным ответом.
Числа и порядок вариантов у каждого кандидата свои; проверять нужно **факты и формулу ответа**.
Сомнительный шаблон: напишите Ване id — он поставит `enabled=False` (шаблон исчезнет из тестов).
