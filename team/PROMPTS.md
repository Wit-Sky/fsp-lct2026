# Как запустить четыре Claude Code

1. Евгений создаёт **публичный репозиторий на GitHub** (лицензия MIT) и кладёт в корень:
   - `CONTEXT.md` ← `CONTEXT.md` (глоссарий)
   - `docs/adr/0001-modules-for-polet-bvs.md` ← `docs/adr/0001-modules-for-polet-bvs.md`
   - `CONTRACT.md` ← `01_КОНТРАКТ.md`
   - `TZ.md` ← `00_ТЗ\ТЗ.txt` — **только локально у каждого, в git не коммитить** (в `.gitignore`; регламент ЛЦТ п. 6.3.5)
   - `team/VANYA.md` ← `03_АГЕНТ_Ваня_бэкенд.md`
   - `team/EVGENY.md` ← `04_АГЕНТ_Евгений_фронтенд_сервер.md`
   - `team/ANTON.md` ← `05_АГЕНТ_Антон_данные_документы.md`
   - `team/STASYA.md` ← `06_АГЕНТ_Стася_тестирование.md`
2. Каждый клонирует репозиторий, открывает в нём Claude Code и пишет **одну** стартовую фразу.

**Ваня:**
```
Прочитай team/VANYA.md, CONTRACT.md и TZ.md. Это твоя инструкция — выполни её целиком, шаг за шагом,
соблюдая контрольные точки и время МСК. Начни с шага 1.
```

**Евгений** (до шага 1 у агента — создание репозитория, если ещё не создан):
```
Прочитай team/EVGENY.md, CONTRACT.md и TZ.md. Это твоя инструкция — выполни её целиком, шаг за шагом,
соблюдая контрольные точки и время МСК. Действия наружу — только после моего «да». Начни с шага 0.
```

**Антон:**
```
Прочитай team/ANTON.md, CONTRACT.md и TZ.md. Это твоя инструкция — выполни её целиком, шаг за шагом,
соблюдая контрольные точки и время МСК. Начни с шага 1.
```

**Стася:**
```
Прочитай team/STASYA.md, CONTRACT.md, CONTEXT.md и TZ.md. Это твоя инструкция — выполни её шаг за шагом,
соблюдая время МСК. Код не меняешь. Начни с шага 1, когда Антон пришлёт карточки для разметки.
```

3. Если агент закончил шаг и ждёт других — дать ему следующий шаг или поручить проверку чужой части (только чтение и отчёт в чат).
4. Если контекст агента переполнился — новый чат с той же стартовой фразой плюс «прочитай docs/progress/<имя>.md и продолжи».
