### Шаг 2 (до 11.10 04:00). Все экраны на моках
**Общее:** главная — что это за сервис в 2 фразах и две большие кнопки «Я кандидат — демо» / «Я работодатель — демо»,
ниже обычная регистрация по email (с вводом кода подтверждения) и вход. Шапка с ролью и выходом.

**Кабинет кандидата** — пошаговый путь со шкалой прогресса «Профиль → ФСП ID → Специализация и грейд → Тест → Категория»:
1. Профиль: форма или загрузка PDF-резюме (поля подставляются, можно поправить), согласие на обработку ПДн (152-ФЗ) — без галочки дальше нельзя,
   настройки приватности (что видно работодателю), кнопка «Скачать мой профиль PDF».
2. «Привязать ФСП ID» → редирект на имитацию → обратно с подтверждёнными результатами (в UI можно «Результаты ФСП»). Кнопка «У меня нет истории ФСП» — путь не блокируется.
   В профиле — дата рождения; если младше 18 — плашка «нужно согласие родителя» с галочкой.
3. Выбор специализации и **самостоятельный выбор грейда** с подсказкой «грейд подтверждается тестом».
4. Тест: 10 заданий по одному, таймер 5:00, прогресс, варианты, поле для числа, перетаскивание для порядка. Без возврата назад.
5. Результат: грейд подтверждён / не подтверждён, θ на шкале с порогами грейдов (recharts), разбор по темам,
   дата следующей попытки, кнопки «Пройти на уровень ниже» (если провал) / «Пройти на повышение» (если `suggest_upgrade`).
6. «Моя категория»: специализация, грейд, статус, история попыток.
7. Приглашения: карточки с компанией, описанием, **зарплатой от–до и пометкой гросс/нетто сразу видна**, принять / отклонить, статусы.
8. Вакансии (дополнительно): список, отклик, «мои отклики» со статусами.

**Кабинет работодателя:**
1. Профиль компании.
2. Мастер «Кого вы ищете»: специализация, грейд, навыки с весом (чипы с ползунком 1–3), чем занимается команда,
   зарплата от–до + гросс/нетто (обязательно), формат работы.
3. Экран категорий: плитки «backend · middle — 42 кандидата, 18 подтверждены, 11 с ФСП» (специализации backend, frontend, БАС-разработчик).
4. Подборка — **главный экран всего продукта**: карточка кандидата = скор 0–100, грейд с бейджем «подтверждён / не подтверждён»,
   совпавшие навыки, бейджи ФСП (или «нет истории ФСП»), раскрывающийся блок «Почему он здесь» со строками explain и вкладом каждого фактора (полоски).
   Фильтры сбоку (соседние грейды, только с ФСП, доп. навыки) — меняют выдачу **без потери исходного запроса**.
   Контакты скрыты замком «откроются после принятия приглашения».
5. Кнопка «Пригласить» → модальное окно: сообщение, зарплата (подставлена из потребности), способ связи → отправка.
6. Поиск по всей базе с фильтрами (специализация, грейд, статус, навыки, ФСП).
7. «Мои приглашения»: статусы sent / viewed / accepted / declined; у принятых — контакты кандидата.
8. Вакансии (дополнительно): опубликовать потребность как вакансию, входящие отклики.

**Качество:** пустые состояния с подсказкой, что делать дальше; загрузка и ошибки показаны; кнопки с понятными глаголами;
контраст текста не ниже 4,5:1; мобильная вёрстка (одна колонка) — желательно.
