# Платформа подбора ИТ-специалистов с подтверждёнными результатами ФСП

Хакатон «Лидеры цифровой трансформации 2026», спецтрек Федерации спортивного программирования.
Работодатель сам находит кандидата в категоризированной базе (специализация × грейд, грейд подтверждён тестом)
и приглашает его с зарплатой; результаты соревнований ФСП поднимают кандидата внутри категории.

> Статус: каркас. Стенд, демо-доступы и запуск одной командой появятся здесь по ходу работы.

## Команда
- Евгений — капитан: фронтенд, сервер, сдача
- Ваня — бэкенд
- Антон — данные, валидация, документация, презентация
- Стася — сквозное тестирование, независимая разметка

## С чего начать
1. `CONTRACT.md` — общий контракт (стек, модель данных, API, стыки, контрольные точки).
2. `CONTEXT.md` — глоссарий.
3. `team/PROMPTS.md` — стартовая фраза для своего ИИ-агентаа; `team/<ИМЯ>.md` — инструкция агента.
4. **ТЗ в репозиторий не кладём** (конфиденциально, регламент ЛЦТ п. 6.3.5): скачать из закрепа чата
   и сохранить текст как `TZ.md` в корне своей копии — файл в `.gitignore`.
