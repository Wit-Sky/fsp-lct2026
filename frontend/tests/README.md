# Проверка ошибок onboarding и таймера

Сценарии воспроизводят ошибки из прогона Стаси. Playwright подменяет ответы API, поэтому тесты не меняют пользователей стенда.
Проверяются: немедленный переход без ФСП; путь в чистом браузере после теста; явное продолжение;
закрытие истёкшей попытки; истечение таймера без ответа; ошибка 404; изоляция аккаунтов; работа без localStorage;
очистка кэша при смене пользователя. По умолчанию используется установленный Google Chrome и ширина 375 px.

В `frontend/`:

```sh
npm install --no-save --package-lock=false playwright
npm run dev -- --host 127.0.0.1 --port 5188
# в другом терминале, тоже из frontend/:
node tests/qa-regressions.cjs
```

Для другого dev-сервера задайте `FSP_QA_URL`. `PLAYWRIGHT_MODULE` позволяет использовать уже установленный Playwright по пути к модулю.
Сборку отдельно проверяйте командой `npm run build`.

Это проверки фронтенда с подменённым API; сквозной прогон на стенде остаётся отдельной проверкой.
